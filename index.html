Technical FAQ: Determinism, Zero-PII & Threat Model

1. Why Notary AI vs. append-only Postgres or S3 Object Lock?

Zero-ops global edge deployment (< 5 ms latency) on Cloudflare Workers + D1 with zero AWS/IAM boilerplate, built-in HMAC-SHA256 receipt signing (server_sig), and native /llms.txt discovery for autonomous agents.

2. What prevents a compromised admin from rewriting the D1 chain?

Single-node hash chaining detects record tampering and silent deletions. For multi-party non-repudiation, clients periodically anchor the /api/head digest externally into Git commits or secondary witness nodes.

3. Why Z3 SMT + Rust instead of an LLM-as-a-Judge guardrail?

Neural guardrails are probabilistic, vulnerable to jailbreaks, and add 300–1000 ms + GPU overhead. Formal Z3 SMT and Rust invariants enforce hard financial and physical limits in microseconds on CPU with 100% determinism.

4. Why 28-digit Python Decimal instead of IEEE 754 float64?

Binary floating-point introduces silent representation drift across multi-period Treasury discounting (DV01) and institutional credit reconciliations. Exact decimal arithmetic guarantees bit-for-bit identical audit proofs across platforms.
